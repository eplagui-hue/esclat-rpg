Com crear el teu servidor gratis

El joc en línia necessita un servidor petit que connecti els dos jugadors. Aquí tens com posar-ne un en marxa sense pagar res.

  1. Descarrega els fitxers del servidor que t'he donat al xat: server.js, package.json i index.html.
  2. Fes-te un compte gratuït a github.com. Crea un repositori nou (botó New), posa-li de nom esclat-aura i marca'l com a Public.
  3. Dins del repositori, prem Add file → Upload files, puja els tres fitxers i prem Commit changes.
  4. Fes-te un compte a render.com entrant amb GitHub. No cal targeta.
  5. A Render prem New → Web Service i tria el repositori esclat-aura.
  6. Omple: Language Node, Build Command npm install, Start Command node server.js, Instance Type Free. Prem Deploy.
  7. Quan posi Live (2-3 minuts), obre l'adreça que et dona Render, del tipus https://esclat-aura.onrender.com. Aquell enllaç ja és el joc complet amb el multijugador funcionant.
  8. Envia el mateix enllaç al teu amic. Un crea la sala, l'altre hi entra amb el codi.

El pla gratuït s'adorm després de 15 minuts sense activitat; la primera vegada que l'obris pot trigar un minut a despertar-se. Mentre jugueu es manté despert.

Amb comandaments: stick esquerre per moure, A saltar, X cop, Y cop fort, B esquivar, RB ki, RT habilitat, LB bloquejar, LT carregar, creueta amunt transformació.

Claus del combat
  • Encadena quatre cops lleugers. Si acabes amb un cop fort, llances el rival enlaire.
  • Just després d'un llançament, salta per perseguir-lo i continuar el combo a l'aire.
  • El cop fort trenca el bloqueig. El bloqueig atura gairebé tot el dany de la resta.
  • Esquiva just abans d'un impacte per fer una esquiva perfecta.
  • Fer i rebre dany omple la barra d'ESCLAT. Plena, et pots transformar fins i tot mentre et colpegen.
  • Transformat, la teva habilitat és més potent, i amb 50 de ki pots llançar l'atac definitiu un cop.
